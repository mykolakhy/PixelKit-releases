# PixelKit

Resize images and compress videos on your computer.

This repository contains downloads, release notes, support, and the source materials and notices for third-party software distributed with PixelKit. The PixelKit application source is maintained in a separate private repository.

## Downloads

Use [Releases](https://github.com/mykolakhy/PixelKit-releases/releases) for available installers. Choose **arm64** for Apple Silicon (M-series) or **x86_64** for Intel Macs. Installers are published only with the matching dependency manifests and source archives.

## Support

Use **Report a bug…** in PixelKit, or [open an issue](https://github.com/mykolakhy/PixelKit-releases/issues/new). Review reports before sharing and do not include personal media or unredacted file paths.

## Third-party software

Each release provides per-architecture `dependencies.json` manifests and `sources.tar.gz` archives for the third-party components included in its installers. Full license texts and notices are also accessible from **Help → Third-party licenses** in the application. These licenses and the rights they grant apply independently of the proprietary PixelKit application code.

The source archives include the collected upstream sources, applicable patches and build recipes, and instructions for replacing the relevant shared libraries. They do not contain PixelKit application source code.

This repository does not grant a license to PixelKit's proprietary source or branding. Third-party material remains governed by its respective licenses.

GitHub's automatically generated **Source code** ZIP/TAR links contain only this public download/support repository's metadata. PixelKit application source is not included.
